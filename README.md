# Murder Drones — Copper 9 Arşivi

GitHub Pages üzerinde yayınlanmaya hazır, yalnızca HTML, CSS ve JavaScript kullanan statik bir fan sayfası.

## Site bağlantısı

GitHub Pages adresi: https://mustafakral562-glitch.github.io/MURDER-DRONES-WEB/

Bu, depo için beklenen Pages adresidir. Pages ayarından yayınlama etkinleştirildikten sonra açılır.

## Yayınlama

1. GitHub'da yeni bir depo oluştur.
2. Bu klasörün içindeki `index.html`, `style.css`, `scriptjs.js`, `.nojekyll` ve `README.md` dosyalarını deponun **en üst seviyesine** yükle. `index.html` bir alt klasörde kalmamalı.
3. Depoda **Settings → Pages** sayfasını aç.
4. **Build and deployment** bölümünde **Deploy from a branch** seç.
5. `main` dalını ve `/(root)` klasörünü seçip kaydet.
6. Yayınlama tamamlandığında Pages ekranında verilen bağlantıyı aç.

GitHub Pages bu projeyi barındırır; sunucu veya backend gerekmez.

## Dosyalar

- `index.html` — sayfa içeriği
- `style.css` — görünüm ve mobil uyum
- `scriptjs.js` — mobil menü ve dinamik yıl
- `.nojekyll` — GitHub Pages'in dosyaları Jekyll ile işlememesini sağlar

Uzi görseli Wikia görsel sunucusundan, yazı tipleri Google Fonts'tan yüklenir; bu iki görsel kaynağı için internet bağlantısı gerekir.

Bu sayfa bir hayran çalışmasıdır; GLITCH Productions'ın resmî sitesi değildir.
