# Murder Drones — Copper 9 Arşivi

GitHub Pages için hazırlanmış, yalnızca HTML, CSS ve JavaScript kullanan statik hayran sayfası.

## Canlı site

https://mustafakral562-glitch.github.io/MURDER-DRONES-WEB-MD./

## Dosyaları GitHub'a yükleme

Bu klasördeki dosyaları deponun en üst seviyesine yükle. `index.html`, `style.css`, `scriptjs.js`, `uzi-worker-drone.png` ve `.nojekyll` aynı kökte olmalı. Özellikle `uzi-worker-drone.png` dosyasını da yükle; Uzi görseli artık bu yerel dosyadan açılıyor.

GitHub deposunda **Add file → Upload files** seç, dosyaları yükle ve **Commit changes**'e bas. Pages ayarında `main` dalı ve `/(root)` seçili olmalı. Yayınlanması birkaç dakika sürebilir.

## Dosyalar

- `index.html` — sayfa içeriği
- `style.css` — görünüm ve mobil uyum
- `scriptjs.js` — mobil menü ve dinamik yıl
- `uzi-worker-drone.png` — Uzi karakter görseli
- `.nojekyll` — GitHub Pages'in dosyaları Jekyll ile işlememesini sağlar

Yazı tipleri Google Fonts üzerinden gelir; özel yazı tiplerinin yüklenmesi için internet bağlantısı gerekir.

Bu sayfa bir hayran çalışmasıdır; GLITCH Productions'ın resmî sitesi değildir.
